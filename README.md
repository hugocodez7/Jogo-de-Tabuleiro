# 🎲 Jogo de Tabuleiro

Projeto desenvolvido em **Python** para a disciplina de **Matemática Aplicada a Computação**, com o objetivo de aplicar conceitos fundamentais de programação no desenvolvimento de um jogo de tabuleiro.

## 📌 Sobre o projeto

O projeto consiste na implementação de um jogo de tabuleiro utilizando Python, explorando conceitos como estruturas de repetição, estruturas condicionais, funções, entrada e saída de dados e manipulação de informações.

O desenvolvimento do projeto também tem como objetivo praticar a organização de código e o uso de **Git e GitHub** para controle de versão.

## 🛠️ Tecnologias utilizadas

* **Python**
* **Git**
* **GitHub**

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/hugocodez7/Jogo-de-Tabuleiro.git
```

### 2. Acesse a pasta do projeto

```bash
cd Jogo-de-Tabuleiro
```

### 3. Execute o programa

```bash
python tabuleiro.py
```

## 🎯 Objetivos

* Praticar lógica de programação utilizando Python;
* Aplicar estruturas condicionais e de repetição;
* Trabalhar com funções e organização do código;
* Desenvolver um jogo utilizando conceitos fundamentais de programação;
* Praticar o controle de versões com Git e GitHub.
